# ReadMe File

This project contains Java implementations the Ant Colony Optimization Algorithm to solve the Team Orienting Problem (TOP)

These algorithms take a TOP instance as input from a `.txt` file and attempt to determine the routes that will maximize the total reward while under the constraints

## Requirements

- Java Development Kit (JDK) 8 or higher
- A terminal or command prompt

Ensure the `jar` command is available by adding the JDK `bin` directory to your system PATH environment variable.

## Setup

1. **Download and Unzip the Folder:**
   - Download the zip file that contains the JAR programs.
   - Unzip it to a directory of your choice.

## Run the Program

1. **Open a Command Prompt/Terminal Window:**

   - Navigate to the folder where the JAR files are located using the `cd` command. For example:
     cd C:\Users\Desktop\Assignment

2. **Execute the JAR File:**

   - Run the `ACO_TOPA.jar` file by typing the following command:

     java -jar ACO_TOPA.jar.jar
         

## Input Text File Path

- When prompted, enter the full path to the text file you wish to process.

  For example:
  C:\Data\file.txt

- After processing the text file, the program will prompt you to add a seed value or 'q' to quit

- Type 'q' when prompted to exit the program.
